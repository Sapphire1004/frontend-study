## 매일 진행하는 방법

1. 해당 일차 문서를 열고 전날 복습 질문에 답합니다.
2. 목표 하나를 골라 직접 코드를 작성합니다.
3. 막히는 부분을 질문하고 설명을 자신의 말로 적습니다.
4. 브라우저 동작과 검사 결과를 확인한 뒤 완료 항목에 체크합니다.
5. 회고와 다음 할 일을 적고 변경 사항을 커밋합니다.

완성 코드를 먼저 채우기보다 목표 → 직접 작성 → 질문 → 확인 순서로 진행합니다. 아직 실행하지 않은 실습의 결과는 기록 대기로 남깁니다.

## 실행하기

프로젝트 루트에서 실행합니다.

```sh
pnpm install
pnpm dev
```

프런트엔드(Vite), 백엔드(Hono), tsrs 타입 검사 watch가 함께 실행됩니다. 터미널에 표시되는 프런트엔드 `Local` 주소로 접속하고, 종료할 때는 `Ctrl+C`를 누릅니다.

```sh
pnpm check        # 린트 · 포맷 · 타입 검사
pnpm build        # 프런트엔드 · 백엔드 빌드
pnpm bench:types  # JS · Go · Rust 타입 검사 속도 비교
```

현재 학습 코드에는 return 이후 실행되지 않는 코드가 남아 있습니다. 수정할 파일과 확인 순서는 [1일차의 남은 실습](docs/day-01.md#남은-실습)에 기록했습니다.
