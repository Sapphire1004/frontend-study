## 시작 전 복습

- [ ] Home에서 저장한 user를 Profile이 읽을 수 있는 이유를 설명한다.
- [ ] useNavigate 같은 Hook을 컴포넌트 함수 안에서 호출하는 위치를 떠올린다.

## 오늘의 목표

- [ ] 일반 변수와 useState의 역할 차이를 이해한다.
- [ ] 클릭 이벤트에서 상태를 변경한다.
- [ ] 배열 상태를 직접 변경하지 않고 새 배열로 갱신한다.

## 작업할 파일

- `frontend/src/pages/deckbuilder/DeckbuilderPage.tsx`
- `frontend/src/components/` — 필요하면 분리할 목록 UI

## 직접 해 볼 실습

- [ ] 숫자를 표시하고 증가·감소 버튼을 직접 연결한다.
- [ ] onClick에 함수를 전달하는 것과 즉시 호출하는 것을 비교해 적는다.
- [ ] 샘플 카드 또는 항목의 배열을 준비한다.
- [ ] 선택한 항목을 state에 추가하고 제거한다.
- [ ] 선택 개수를 화면에 표시한다.
- [ ] 배열을 렌더링할 때 항목을 구분할 수 있는 key를 사용한다.

## 완료 확인

- [ ] 버튼 클릭 뒤 화면의 숫자 또는 목록이 갱신된다.
- [ ] 상태 변경 전후의 값을 설명할 수 있다.
- [ ] 배열 추가·제거가 기존 배열을 직접 수정하지 않는 방식이다.
