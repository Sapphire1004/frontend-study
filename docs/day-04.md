## 기록 정보

- 권장 학습일: **2026-11-02 (Asia/Tokyo)**
- 실제 학습일: 기록 대기
- 상태: **예정 · 아직 실습하지 않음**
- 이 문서는 학습 제안입니다. 실제 과제가 있으면 목표를 갱신합니다.

입력값을 React 상태로 다루고, 저장 전에 조건을 확인하는 연습입니다.

## 시작 전 복습

- [ ] state가 바뀌면 어떤 화면이 다시 계산되는지 설명한다.
- [ ] 자식에게 이벤트 함수를 전달하는 방법을 떠올린다.

## 오늘의 목표

- [ ] value와 onChange를 연결한 입력 폼을 만든다.
- [ ] form 제출 이벤트와 버튼 클릭을 구분한다.
- [ ] 유효하지 않은 입력에 안내 메시지를 표시한다.

## 작업할 파일

- `frontend/src/pages/profile/ProfilePage.tsx`
- `frontend/src/pages/update-deck/UpdateDeckPage.tsx`

## 직접 해 볼 실습

- [ ] 닉네임 또는 덱 이름 중 하나를 입력하는 폼을 만든다.
- [ ] input과 label을 연결한다.
- [ ] 입력값을 state로 관리한다.
- [ ] 빈 문자열이나 공백만 입력했을 때 저장하지 않도록 처리한다.
- [ ] 검증에 실패한 이유를 화면에 표시한다.
- [ ] 제출 버튼과 일반 버튼의 type을 명시한다.
- [ ] 제출할 때 의도하지 않은 문서 이동이나 새로고침이 생기는지 확인한다.

## 완료 확인

- [ ] 입력과 화면에 표시된 값이 함께 바뀐다.
- [ ] 올바르지 않은 입력을 구분해 안내한다.
- [ ] 제출과 일반 버튼 동작을 구분할 수 있다.

## 복습 질문

1. value만 지정하고 onChange를 연결하지 않으면 어떤 일이 생기는가?
2. form 제출과 버튼 클릭은 어떤 점이 다른가?
3. 이벤트의 기본 동작을 막는 것과 페이지를 이동하는 것은 어떻게 다른가?
