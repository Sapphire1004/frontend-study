## 기록 정보

- 권장 학습일: **2026-11-04 (Asia/Tokyo)**
- 실제 학습일: 기록 대기
- 상태: **예정 · 아직 실습하지 않음**
- 이 문서는 학습 제안입니다. 실제 과제가 있으면 목표를 갱신합니다.

브라우저를 새로 열었을 때도 학습용 데이터를 다시 읽어오는 연습입니다.

## 시작 전 복습

- [ ] 요청의 로딩·성공·실패 상태를 구분한 방법을 설명한다.
- [ ] 화면 상태와 외부에 저장된 데이터를 구분한다.

## 오늘의 목표

- [ ] React state와 localStorage의 역할을 구분한다.
- [ ] 문자열로 저장한 데이터를 다시 읽어 상태에 반영한다.
- [ ] 저장 데이터가 없거나 올바르지 않을 때의 동작을 정한다.

## 작업할 파일

- `frontend/src/pages/deckbuilder/DeckbuilderPage.tsx`
- `frontend/src/pages/update-deck/UpdateDeckPage.tsx`
- `frontend/src/lib/` — 필요하면 저장 처리를 분리

## 직접 해 볼 실습

- [ ] 저장할 데이터의 최소 구조를 타입으로 적는다.
- [ ] 이름과 선택 항목 같은 학습용 데이터를 state로 만든다.
- [ ] 사용할 localStorage 키 이름을 정한다.
- [ ] 저장 버튼에서 데이터를 문자열로 변환해 저장한다.
- [ ] 새로고침 뒤 저장된 값을 읽어 화면에 복원한다.
- [ ] 저장된 값이 없을 때 기본 화면을 표시한다.
- [ ] JSON 해석 실패나 예상과 다른 데이터 구조를 처리한다.
- [ ] 저장 데이터 삭제 또는 초기화 동작을 확인한다.

## 완료 확인

- [ ] 새로고침 후 저장한 학습용 데이터가 복원된다.
- [ ] 저장 데이터가 없어도 페이지를 사용할 수 있다.
- [ ] TypeScript 타입 선언과 실제 저장값 검증의 차이를 설명한다.

## 복습 질문

1. state와 localStorage는 어떤 점이 다른가?
2. JSON.parse 결과에 타입을 붙이면 실제 데이터 구조도 보장되는가?
3. 화면 간 이동과 새로고침에서 어떤 데이터가 남는가?
