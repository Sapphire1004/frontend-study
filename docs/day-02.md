## 기록 정보

- 권장 학습일: **2026-10-31 (Asia/Tokyo)**
- 실제 학습일: 기록 대기
- 상태: **예정 · 아직 실습하지 않음**
- 이 문서는 학습 제안입니다. 실제 과제가 있으면 목표를 갱신합니다.

반복되는 화면을 작은 컴포넌트로 나누고, 부모가 자식에게 값을 전달하는 연습입니다.

## 시작 전 복습

- [ ] Link와 navigate의 차이를 설명한다.
- [ ] JSX를 여러 줄로 반환할 때 return과 여는 괄호의 위치를 확인한다.

## 오늘의 목표

- [ ] 페이지 컴포넌트와 재사용할 UI 컴포넌트를 구분한다.
- [ ] props로 문자열과 이벤트 함수를 전달한다.
- [ ] props 타입을 작성하고 전달받은 값을 직접 변경하지 않는다.

## 작업할 파일

- `frontend/src/components/` — 직접 만들 재사용 UI
- `frontend/src/pages/home/HomePage.tsx`
- `frontend/src/pages/profile/ProfilePage.tsx`

## 직접 해 볼 실습

- [ ] 두 페이지에서 반복되는 UI 하나를 찾는다.
- [ ] 컴포넌트 이름과 받아야 하는 값을 먼저 적는다.
- [ ] PageTitle 같은 제목 컴포넌트를 직접 만들고 제목을 props로 전달한다.
- [ ] 두 페이지에서 같은 컴포넌트를 다른 값으로 사용한다.
- [ ] 컴포넌트의 props 타입을 직접 정의한다.
- [ ] Tailwind className으로 필요한 스타일을 붙여 본다.

## 완료 확인

- [ ] 같은 UI 컴포넌트를 두 곳에서 재사용한다.
- [ ] 하드코딩한 값을 props로 바꾸는 이유를 설명한다.
- [ ] props에 없는 값을 넘겼을 때 타입 검사 결과를 확인한다.

## 복습 질문

1. props와 함수 인자는 어떤 점이 비슷한가?
2. 페이지마다 다른 값과 공통 UI 구조를 어떻게 구분했는가?
3. 전달받은 props를 직접 바꾸지 않는 이유는 무엇인가?
