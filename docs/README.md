## 하루의 사용 순서

1. **복습:** 전날 문서의 복습 질문에 자신의 말로 답합니다.
2. **목표:** 오늘 목표 중 하나를 선택합니다.
3. **실습:** 해당 페이지 파일에서 직접 작성합니다.
4. **질문:** 이해되지 않는 코드나 오류를 짧게 적고 질문합니다.
5. **검증:** 브라우저에서 확인하고 `pnpm check` 결과를 기록합니다.
6. **기록:** 배운 점, 남은 질문, 다음 할 일을 적습니다.
7. **저장:** 변경 파일을 확인하고 GitHub에 커밋·푸시합니다.

체크박스는 직접 실행하고 결과를 확인한 뒤에 체크합니다. 코드가 준비되어 있는 것과 스스로 설명할 수 있는 것은 따로 확인합니다.

하루 기록을 마치면 루트 README의 현재 학습 링크와 두 목차의 상태를 실제 진행 상황에 맞게 갱신합니다. 다음 일차는 문서의 다음 날 링크로 이어갑니다.

## 공통 명령

프로젝트 루트에서 실행합니다.

```sh
pnpm dev
pnpm lint
pnpm format:check
pnpm typecheck
```

`pnpm check`는 린트 → 포맷 → 타입 검사 순서로 실행하므로 앞 단계가 실패하면 뒤 단계는 실행되지 않습니다. 개별 명령으로 어느 단계의 문제인지 확인할 수 있습니다.

실습 중인 오류가 남아 있으면 검사 실패도 그대로 기록하고, 수정 후 결과를 추가합니다. 포맷을 적용하려면 `pnpm format`을 사용합니다.
